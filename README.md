# Pelu Assistant - Chrome Extension

A tactical productivity extension designed to streamline the job application process by autofilling forms and injecting pre-defined text blocks.

## 🚀 Features

-   **Basic Info Autofill:** Automatically fills in common fields like First Name, Last Name, Email, and Phone.
-   **Text Arsenal:** Store and inject complex text blocks (like Professional Summaries or Work Experience) with a single click.
-   **Bilingual Support:** Store and inject text in both Spanish and English, with an easy toggle in the popup UI.
-   **Modern UI:** A clean, elegant, and branded interface for managing your data.

## 🛠️ Tech Stack

-   Chrome Extension Manifest V3
-   JavaScript (ES6+)
-   HTML5
-   CSS3

## ⚙️ Installation

1.  Download or clone this repository.
2.  Open Chrome and navigate to `chrome://extensions`.
3.  Enable "Developer mode" in the top right corner.
4.  Click on "Load unpacked".
5.  Select the project folder.
6.  The "Pelu Assistant" icon will appear in your Chrome toolbar.
